# Privacy

IDT-YT Downloader stores preferences, shortcuts, browsing state, download history
and unfinished queues on the computer running it. The legacy profile location is
`%LOCALAPPDATA%\VedaBoat`; partial/source audio is under `.vedaboat` in the chosen
download destination. These locations are retained for compatibility.

Browsing and downloading contact Desire Tree or YouTube and their content hosts.
The manual YouTube-support update contacts GitHub for yt-dlp and QuickJS releases.
Those services receive normal network request information, including the user's
IP address and requested URLs. Their own policies apply.

The app has no account system, advertising or application analytics service.
Downloads are manually started. It does not upload your recordings or local
profile to the project maintainers.

Error details, filenames and screenshots can contain local paths or recording
links. Remove personal information before posting them in a public GitHub issue.
