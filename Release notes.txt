IDT-YT Downloader 2.4.0

Single portable EXE is the main download: double-click to run, with no installation
or manual extraction. Resources unpack automatically while running. A ZIP folder
alternative is also available. Both use the same saved preferences, shortcuts,
queue, download history, destination assignments and partial files.

The first launch displays the Windows Python runtime conditions once. These apply
only to the included Microsoft runtime components. Help > Licenses and source
provides the complete notices and a link to the matching source downloads.

The audio tools are now built from a smaller, fully recorded source set, reducing
package size. MP3 defaults, output paths, selection/navigation, themes, resume and
independent YouTube-support updates remain compatible with 2.3.0. System is the
default theme; the D3 outline-folder icon is retained.

Matching dependency source, the application's source, checksums and verification
results accompany the Windows downloads. The app is unsigned; Windows may show
an unrecognized-app warning. Download only from the project's official release.
